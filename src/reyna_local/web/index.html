    Ver la estructura del JSON

    La cabecera es un objeto, por ejemplo {"FECHA": 20261118}. Las líneas forman una lista de objetos, por ejemplo [{"CANT": 1}]. Completa la estructura con los campos y códigos que requiere tu libro.
