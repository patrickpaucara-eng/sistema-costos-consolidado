# OT-C24 · Entregables funcionales

La exportación lee los bloques del resultado publicado y nunca recalcula costos. Frenosa 2010-12 y SERVITEC 2025-07 se contrastan campo a campo en las hojas añadidas. Los flotantes que perderían precisión al guardarse en Excel se preservan como texto decimal; los demás permanecen numéricos. Las hojas sin datos no representan un cero.

La orden queda parcial: no se ha acreditado el recorrido único con T14, los casos manuales en Word, ni todas las pantallas del manual. La API de proyección granular no forma parte de los JSON publicados. Ver `ordenes/BLOQUEOS_CODEX.md`.
