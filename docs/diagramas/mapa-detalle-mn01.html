3 · El reparto por dentro (Oria)

Cada etapa usa las dos matrices de Oria: configuración (qué criterio y cuánto le toca a cada destino) y cálculo (monto del origen × medida ÷ total). Lo que sale de una etapa es el monto de origen de la siguiente.

P1 · P2 · P3material, personal y servicios directos → orden o actividad
→
P4Aindirectos → centros o actividades (nunca ambos)
→
P4Bapoyo → productivos
entre apoyos: recíproco
→
P4Dcentro de actividad → actividades
→
P4Eescalonado: estratégicas → apoyo → operativas
mismo nivel: recíproco
→
P4Cactividades o centros → orden, por inductor
→
P5 · P6 · P7administración, ventas, financieros → orden (solo costo integral)

La capacidad no usada (ocio) y las pérdidas viajan con etiqueta por la misma cadena; la síntesis decide: REAL las muestra aparte, CONTABLE las manda a gasto (NIC 2).
